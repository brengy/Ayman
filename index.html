ربط GitHub (للإدارة بس)

بعد الربط، أي سعر تأكده بيتحفظ في prices.js جوه الريبو، ويظهر لكل الزوار خلال دقيقة. التوكن بيتحفظ في المتصفح ده بس.

إزاي أعمل توكن؟
  1. GitHub ← صورتك ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. Repository access: Only select repositories واختار ريبو الصفحة.
  3. Permissions ← Repository permissions ← Contents: Read and write.
  4. Generate، وانسخ التوكن (بيبدأ بـ github_pat_) والصقه هنا.
